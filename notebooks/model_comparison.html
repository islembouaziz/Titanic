Differences between the models

XGBoost Regularized boosted trees

Optimized gradient boosting: adds L1/L2 regularization, second-order gradients, column subsampling and parallel tree building.

Strengths

  • Often the best accuracy
  • Built-in regularization
  • Fast and scalable, handles missing values

Weaknesses

  • Most hyperparameters to tune
  • Less interpretable
  • Extra dependency (xgboost)

Best params: colsample_bytree=0.8, learning_rate=0.1, max_depth=4, n_estimators=100, subsample=1.0

Gradient Boosting Boosted trees (sequential)

Builds many small trees one after another; each new tree corrects the errors of the previous ones (sklearn implementation).

Strengths

  • High accuracy on tabular data
  • Handles non-linear + interactions
  • Flexible loss and parameters

Weaknesses

  • Slower to train
  • Many hyperparameters
  • Can overfit if learning_rate / n_estimators badly set

Best params: learning_rate=0.05, max_depth=3, n_estimators=200, subsample=0.8

Random Forest Bagged trees (parallel)

Trains many deep trees in parallel on random samples of rows and features, then averages their votes.

Strengths

  • Robust, few tuning needs
  • Reduces tree overfitting
  • Handles non-linear + interactions

Weaknesses

  • Less interpretable than one tree
  • Larger and slower at prediction
  • Usually slightly behind boosting

Best params: n_estimators=300, max_depth=10, min_samples_split=10, min_samples_leaf=1

Decision Tree Single tree

Splits the data with a series of if/else questions (e.g. "Sex = female?", "Age < 10?") until it reaches a prediction.

Strengths

  • Very easy to read and explain
  • No scaling needed
  • Captures non-linear rules

Weaknesses

  • Overfits easily
  • Unstable: small data change = different tree
  • Usually less accurate than ensembles

Best params: criterion=gini, max_depth=5, min_samples_leaf=1, min_samples_split=10

Logistic Regression Linear model

Learns one weight per feature and combines them linearly, then converts the score into a survival probability (sigmoid).

Strengths

  • Fast, simple, hard to overfit
  • Interpretable coefficients
  • Gives calibrated probabilities

Weaknesses

  • Only linear boundaries
  • Needs scaling / encoding
  • Misses feature interactions (e.g. Sex x Pclass)

Best params: C=0.1, penalty=l2, solver=lbfgs

How to choose

  • Best accuracy on tabular data: XGBoost or Gradient Boosting.
  • Need to explain decisions (reports, stakeholders): Decision Tree or Logistic Regression.
  • Small dataset like Titanic: differences are small; prefer the simplest model within ~1 pt of the best (check the std of CV).
  • Selection criterion used here: highest CV accuracy (more reliable than a single validation split), validation accuracy as tie-breaker.
